# SeenLens

SeenLens is a one-time AI readiness audit for websites, with a fix report.

- Free scan: 43 checks on one URL, with a score and up to three findings (issues first, then what the page does well).
- Full report: one payment per URL, no subscription. Every fix with evidence, code to paste where the facts allow, and a PDF.
- Free tools: AI crawler checker, llms.txt checker, Content Signal generator, schema checker, GEO and AEO audit pages.

Website: https://seenlens.com
